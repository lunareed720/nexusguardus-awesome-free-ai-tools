# 🔥 awesome-free-ai-tools

> A curated, open-source directory of genuinely free AI tools — no credit card, no 3-day trial, no hidden tiers.

[![License: CC0-1.0](https://img.shields.io/badge/License-CC0%201.0-brightgreen.svg)](https://creativecommons.org/publicdomain/zero/1.0/)

---

## 🤖 What is this?

A constantly updated, community-curated catalog of AI tools that are **actually free forever** or offer a genuinely generous free tier — verified by real users, not sponsored listings. No affiliate links. No paywalls hiding behind "free trial."

We rate each tool on: **truly-free**, **no-credit-card**, **utmost-limits**, and **privacy-respecting**.

---

## ⭐ Why this repo gets stars

- **Every tool is verified** — no sponsored garbage
- **Privacy-first googlability** — quick browser search with no account
- **Crowdsourced free-tier data** — community updates limits monthly
- **Compare side-by-side** — free-vs-paid table for every AI tool
- **Dark web of free AI** — hidden gems not on any blogspam list
